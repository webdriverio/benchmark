What does it cost an agent to get a browser task right?

Coding agents run the same browser tasks with different tools, with the same model, harness and prompts for every tool. We measure tokens, cost, time and whether the task was done. Every run, prompt and check is public.

Latest version of each tool

Medians per task run. Tokens include cache reads and writes. Lower is better, except success. The range under a success rate is its 95% confidence interval: differences inside it can be chance.
